## Features

- Activates Windows Vista through Windows 11 and Windows Server editions through a KMS server
- Activates Microsoft Office 2010, 2013, 2016, 2019, 2021 and Office 365 via KMS
- Runs from any folder or USB drive without installation or system changes
- Installs, changes and removes product keys and displays the current activation status
- Creates a scheduled task that renews the activation automatically
